## 学生考勤管理系统
项目具体介绍如下：

### 一、系统功能
#### 教师端功能
1. 学生信息管理：对学生账号进行新增、修改、删除，支持按学号、姓名检索、排序，可批量删除多条学生数据；
2. 课程管理：录入、编辑课程名称、上课时间、授课教室信息，统一管理全部授课课程；
3. 考勤记录管理：查看所有学生打卡记录，可按课程、日期条件筛选考勤数据，支持考勤表格导出Excel文件，可删除无效考勤记录；
4. 请假审批：查看学生提交的请假申请，执行批准或驳回操作，并填写审批意见；
5. 批量导入功能：上传Excel表格，批量导入全体学生信息，系统自动生成学生账号，初始统一密码为123456。
 
#### 学生端功能
1. 课程打卡：仅在课程规定的上课时间段内可以打卡，后台自动判断出勤状态，分为正常出勤、迟到；
2. 请假申请：自主选择对应课程、请假起止日期、填写请假事由，提交申请等待教师审核。
 
#### 通用安全与统计功能
1. 权限管控：使用Spring Security划分师生角色权限，教师拥有全部管理权限，学生仅可操作个人打卡、请假功能，禁止越界访问；
2. 账号安全：用户登录密码采用BCrypt加密方式存入数据库，不储存明文密码，提升信息安全性；
3. 考勤数据统计：页面自动统计展示每位学生打卡总次数、迟到次数、请假次数，由数据库聚合查询实时展示。
 
### 二、项目技术栈
后端：Spring Boot 3.2.5、Spring Security、Spring Data JPA、Hibernate
前端：Thymeleaf、Bootstrap 5、Bootstrap Icons
数据库：MySQL 8.0
辅助工具：Maven、Apache POI（Excel导入导出）、Lombok
